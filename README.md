# QuickShow - Movie Ticket Booking Website

A full-stack movie ticket booking web application built with React and modern web technologies. The application allows users to explore movies, view available shows, and book movie tickets through an interactive interface.

## Features

- Browse movies
- View movie details
- Explore available shows
- Movie ticket booking
- User authentication
- Responsive user interface
- Backend API integration

## Technologies Used

- React
- JavaScript
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
